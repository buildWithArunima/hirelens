Build a full-stack Todo app.

- Users can create, view, complete and delete todos.
- Backend: a REST API (Node/Express or similar) with endpoints for the todo operations.
- Persist todos in a database (SQLite, MongoDB or Postgres). In-memory storage is acceptable but should be called out.
- Frontend: a React (or similar) UI that talks to the API.
- Basic input validation (no empty titles) and sensible error handling.
- Include a README explaining how to run the project.
